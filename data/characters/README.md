# Исходные списки персонажей

Собраны 01.11.2026 для инвентаризации данных ДЗ №2.

| Книга | Файл | Источник | Состав |
| --- | --- | --- | --- |
| Ионыч | [ionych.csv](ionych.csv) | [Сдам на 5](https://www.sdamna5.ru/ionych_harakteristiki) | 8 отдельных персонажей и 1 группа «Семья Туркиных» |
| Преступление и наказание | [crime.csv](crime.csv) | [Literaturus](https://www.literaturus.ru/2020/07/geroi-prestuplenie-i-nakazanie-opisanie-personazhi-spisok-tablica.html) | 28 отдельных персонажей |

Сохранены названия записей в порядке источника, ссылка и статус проверки.
Тексты характеристик не копируются. `source_label` — исходное обозначение;
`name` — то же обозначение без варианта в скобках; `aliases` — только явно указанный
в заголовке вариант (Котик). Это не полный словарь имён: варианты из описаний ещё не извлечены.
`source_index` — номер строки источника, а не постоянный идентификатор героя.

Семья Туркиных сохранена отдельной группой, а не пятым человеком рядом с её членами.
Неоднозначные обозначения вроде «Мещанин» оставлены как в источнике.
Все строки имеют `review_status=not_checked_against_book`: полнота и корректность
ещё не проверены по произведениям. Наличие списка не означает наличие готового gold.

Воспроизведение из корня репозитория:

```bash
python3 scripts/collect_characters.py
```

Python 3.11+, без дополнительных зависимостей. При отсутствии кэша нужен интернет.
Исходный HTML хранится локально в `data/raw/`, не публикуется; URL и SHA-256 сохранены
в [sources.json](sources.json). Скрипт извлекает заголовки записей, исключает рекламную
строку таблицы и сохраняет CSV в UTF-8.
